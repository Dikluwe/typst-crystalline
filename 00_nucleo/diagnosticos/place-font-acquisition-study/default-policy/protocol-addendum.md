# Default font-policy controls

The explicit-font cohort showed first catalog demand in eval_set_rule and a vanilla font discovery span even for empty/nontext inputs. These results are retained, not discarded. This second cohort removes only the explicit font declaration in both engines. Same page, bodies, image, available font universe, executables and sampling protocol. The engine defaults are preserved; text controls are not asserted to have identical resolved font selection without output validation. This controlled declaration change is distinct from a production optimization.

Execute the same run module with R set to this directory. Raw results and seals remain separate; do not pool the two cohorts. No builds or code changes between cohorts.
