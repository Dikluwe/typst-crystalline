# Atomização de font_metrics

## Resultado e escopo

Métricas de face única, extratores matemáticos, backend de fallback, resolução
por estilo/cobertura e caches têm consumers próprios. O hub conserva as structs
públicas, constructors, Clone e reexports dos helpers já usados pelo shaper e
pelo exportador. Nenhuma API pública, fórmula, unidade, catálogo ou política de
cache foi alterada. Os corpos das funções e os testes existentes foram movidos.

| Consumer | Linhas após formatação | Testes locais |
| --- | ---: | ---: |
| `03_infra/src/font_metrics.rs` | 107 | 2 |
| `03_infra/src/font_metrics/basic.rs` | 609 | 7 |
| `03_infra/src/font_metrics/caches.rs` | 313 | 2 |
| `03_infra/src/font_metrics/fallback.rs` | 1340 | 7 |
| `03_infra/src/font_metrics/math.rs` | 635 | 2 |
| `03_infra/src/font_metrics/resolution.rs` | 566 | 4 |

O monólito original tinha 3456 linhas; o hub atual tem 107. A comparação
mecânica dos 135 corpos de funções antes/depois não encontrou diferenças,
normalizando whitespace e vírgulas de formatação. Essa comparação não é prova
de paridade com a linguagem; comprova apenas preservação na movimentação.
Os 24 nomes de testes foram conservados sem duplicação.

Cada consumer possui um Prompt L0 proprietário em
`00_nucleo/prompts/infra/font_metrics/`; o hub usa
`00_nucleo/prompts/infra/font_metrics.md`. Os owners fallback e resolution pinam
as claims compartilhadas de fonts/fallback-selection.toml. O L0 monolítico
anterior está preservado como registro histórico em
`00_nucleo/diagnosticos/font-metrics-l0-before-atomization.md`, não como owner
materializável. A classificação é mudança interna, fluxo contínuo ADR-0127.
