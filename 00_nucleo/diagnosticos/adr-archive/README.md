# Archived architecture records

This directory preserves records removed from the canonical ADR set. Archived
records are historical evidence and do not govern current implementation.

- superseded/: revoked decisions or decisions replaced by a later ADR;
- process-roadmaps/: execution plans, cumulative roadmaps, and step records
  that were misclassified as architectural decisions;
- adr-0113-draft-stub-vs-fallback-portuguese.md: the unnumbered drafting input
  superseded by canonical ADR-0113.

Use redirects.tsv to resolve former canonical paths. Historical materialization
documents retain the paths that were true when they were written; they are not
silently rewritten to present-day locations.

Archiving never promotes, revokes, or changes a decision. Any normative clause
found only in a process/roadmap record must be extracted into an active ADR or
the owning L0 prompt before the archived record can be treated as purely
historical.
