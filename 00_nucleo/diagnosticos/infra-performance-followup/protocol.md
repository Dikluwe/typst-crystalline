# Post-correction release performance protocol

Measure the current working tree after commits 3dee39ead and 0fea906e1 against vanilla pin 9f2b6e8715237cb086899a42873660fe744622e8. No production, L0, ADR or existing benchmark changes are allowed in preparation or measurement. Original sealed results remain historical, with no before/after causal estimate from different runs. The unknown-axis bug's failed prior export is not a baseline for successful export latency.

Prepare all builds serially before any timing: release CLI, all eight benchmarks with cargo bench --manifest-path benches/Cargo.toml --no-run, release private core test executable, and an unchanged copy of the existing public Tekt/vanilla font comparison harness. Cargo JSON verifies opt-level 3 and disabled debug assertions/overflow checks. Archive binaries and record SHA-256, lockfiles, toolchain, flags and host. The diagnostic harness uses pinned staged vanilla sources and its own lockfile; it is not the ratified vanilla CLI build. Validate original and staged source hashes plus the ratified CLI SHA-256 before freezing.

Run three rounds for all eight existing benchmark targets. Six standard Criterion targets use 30 samples, 200ms warmup, 600ms target measurement and 5000 resamples; observation and stdlib retain their supported launchers' fixed 30/150ms/300ms settings. Launcher build/profile checks happen before Criterion sampling; launchers are warmed before collection. Output destruction/setup rules remain those of benches/README.md and the existing benchmark audit, copied here by reference without pretending to isolate stream internals. CRITERION_HOME directs samples exclusively to this new dataset. No timed cargo build or wall time of launcher startup is reported as an operation cost.

Run the copied font harness in three fresh processes, reversing engine/fixture order in r2. Its 96 cases retain their earlier fixture/control definitions and 30/200ms/600ms/5000 settings. Generic constructors and metadata+cmap compositions are distinct; first access includes each API's loading/initialization composition while retained access uses initialized slots/stores. Full boundaries are in the prior sealed font-microbenchmarks-vanilla/protocol.md. Do not sum these into CLI phases.

CLI comparisons use the five previously qualified fixtures and the same project-font directory, options and pinned vanilla binary. New process each invocation, filesystem caches warm, two unrecorded warmups per engine/block. Three rounds; twelve alternating-order pairs per fixture without tracing, six pairs per fixture with tracing. Rayon and vanilla jobs are one; CPU affinity is 4. No host page-cache flush or governor change. Both engines receive identical input/font bytes and page/tagging/pretty options. Existing math exclusion remains because font equivalence was not established.

Instrumented cohorts are separate populations. For Tekt, record broad eval, introspection/context/layout/shaping, PDF export and wall residual; for vanilla parse disjoint initial-eval, stabilization-iteration and complete-PDF trace spans. Residual includes setup, resource acquisition outside timers, I/O, teardown and instrumentation. Nested font discovery spans are not added again. Only compatible intervals from the same fixture/population may be related to wall time. Plain wall medians are not decomposed by traced means.

A 30-second quiet gate precedes each cohort block (all existing targets, font cases, or all CLI fixtures of one round). Targets/fixtures within a cohort run sequentially without a second gate; monitoring is continuous throughout the cohort. Check processes every 100ms; reject any other build, test or benchmark. Compare HEAD, all production consumers/prompts/benches/manifests, diagnostic inputs/scripts, original/staged upstream, font files/catalog configuration and executable fingerprints before/after. Discard the whole block on mutation or contamination and retain raw rejected data. A maximum of three attempts per block bounds retries; never silently replace evidence.

Report all accepted samples and outliers, means, medians, SD, p05/p95/min/max per round and pooled CLI distributions. Absolute micro costs are stable only when the three round means have mean-versus-median difference <3% and range/median <=5%; failures remain exploratory. CLI ratio/delta is calculated per pair. Compare historical measurements descriptively only; no historical subtraction is a causal effect of these fixes.

After performance samples finish, run the prepared language-demand control untimed. Its direct rustybuzz result is an algorithmic control, not a vanilla full-pipeline oracle or a performance metric. Do not edit consumers while samples are running. Any new defect requires separately recorded discriminating evidence and L0-first RED→GREEN after this frozen measurement window.
