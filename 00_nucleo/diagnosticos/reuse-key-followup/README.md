# Reuse key follow-up protocol

Behavioral controls only; no timing or performance attribution. Run `PYTHONDONTWRITEBYTECODE=1 python3 run.py` from this directory. The runner builds offline release, repeats with --locked, fingerprints consumers and pinned vanilla sources before/after, and preserves the incoming tracked patch. Reject results if fingerprints change.

For each fixture face 0, inspect positive wght range using a 0.5 grid. At advance-vector transitions, bisect positive f32 bit patterns to adjacent coordinates. Only consider pairs with equal four-decimal formatting. Require different fresh public shape_document output before testing mixed AB and BA. Stop at the first discriminating pair per font; bounded search is not exhaustive. Use supported characters from xHmA0aeW. All other TextStyle fields stay at defaults except explicit family, 12pt size, and wght.

The limited diagnostic World retains an Arc-owned book/Font pair while rebuilding the source SystemWorld for each revision. It exercises main/source/font only; it is not a complete CLI, fallback, watch, package, plugin, or cache invalidation implementation. Replace the whole pair explicitly when switching the font universe. No automatic generation discovery is tested. Scratch main.typ is restored after execution.

No production APIs, benchmarks, L0s, or previous evidence are changed. This experiment does not establish a speed gain or vanilla parity.
