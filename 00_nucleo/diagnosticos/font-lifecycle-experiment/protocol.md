# Font lifecycle controlled experiment

User-authorized experiment against vanilla pin 9f2b6e8715237cb086899a42873660fe744622e8. The preserved before executable is the exact release CLI from the performance baseline. Production changes are internal: no public signature, CLI option, family priority, shaping rule or pipeline business phase changes. L0s precede implementation; changes remain reviewable and preserve the incoming dirty tree.

Compare before, demand-driven catalog, and demand-driven catalog plus interval coverage construction. Retain exact source snapshots, executable hashes and Cargo profiles for every variant. System coverage is still extracted during discovery using temporary fontdb bytes, preventing the P1410 retained-mapping failure. Do not add a disk cache. The existing explicit preload API remains available; ordinary CLI compilation does not force it. Empty exported font sets do not request the catalog; layout may still require real baseline/cap-height metrics, including on shape documents. No layout metric is replaced to suppress that legitimate demand.

Three rounds with twelve alternating quadruplets per qualified baseline fixture, two warmups per variant and fixture, CPU 4, Rayon one, the baseline font universe and options. Rotate execution order. Fresh child processes and warmed filesystem cache. Record all raw spawn-to-wait wall times, CPU and RSS (wait4 RSS may inherit a parent floor), stdout/stderr and PDFs. Every admitted block requires unchanged consumer/input and executable fingerprints, a quiet gate and no observed concurrent builds/tests/benchmarks. Poll at 100 ms. Reject complete contaminated blocks. Instrumented samples form a separate population; never subtract phase means from plain medians.

Validate output pages, dimensions, normalized text and selected text-font resources on representative PDFs for each round and variant. These controls do not establish global parity. Run existing font/world/pipeline regressions serially and P1410 outline/raw probes under the unchanged 512 MiB address-space limit. Keep regular tests/builds outside all timed blocks. Repeated-world unit cases verify catalog retention and concurrent initialization; CLI watch currently recreates a world and is a separate lifecycle integration concern unless changed explicitly in this experiment.

Only task-owned files receive formatting or hash updates. No global formatting or global hash reseal. Preserve the original baseline dataset unchanged.
