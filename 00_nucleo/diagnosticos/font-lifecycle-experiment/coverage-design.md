# Internal coverage construction experiment

Measured source mechanism, not a timing result: pinned vanilla `crates/typst-library/src/text/font/info.rs:119-134` builds compact coverage inside each ordered Unicode cmap subtable and unions ranges. Its general `Coverage::from_vec` at `info.rs:296` still sorts/deduplicates codepoints. Current Tekt `03_infra/src/fonts.rs:403` concatenates all Unicode subtable codepoints and invokes its general vector constructor.

The experiment preserves the existing `Coverage::from_codepoints(impl Into<Vec<u32>>)` API and alternating gap/count representation. Compact contiguous sequences into inclusive intervals, sort the intervals and merge overlap/adjacency before encoding. Extend an interval at either edge and ignore points already inside its last interval; arbitrary order and duplicates remain supported. No font bytes or I/O enter L1. L3 still collects its input vector: this is an adaptation of the compact-range mechanism, not the literal vanilla streaming builder and not elimination of that vector.

Independent controls compare membership and ordered iteration with a BTreeSet on empty inputs, duplicate/overlapping subtables, reversed ranges, pseudorandom order, gaps, zero and the Unicode maximum. Catalog probes compare complete metadata controls, including canonical encoded coverage, outside the timed discovery interval. The catalog probe includes system discovery, metadata/coverage parsing and slot/book construction with warmed filesystem caches; caller setup and result hashing/destruction are outside discovery. Destruction is separately recorded. Do not subtract its durations from end-to-end fixtures: the catalog probe contains system fonts, while the end-to-end universe also has embedded/project fonts.


Historical evidence is retained byte for byte in `originals/00_nucleo/prompts/entities/font_book.md.snapshot`, with its initial SHA-256 in `initial.json`. The former L0 describes P937 replacing a coarse bitmap and P942 keeping the vector-based constructor and stable sorting. Its acquisition narrative predates P1410 and does not authorize mapping all current system font slots. This experiment preserves exact coverage and the current L3 memory policy. The former cross-owner Font/mmap section is now a reference to the proven `00_nucleo/prompts/world-types.md` owner (confirmed by the consumer header), and the inaccurate constant-time Coverage clone / logarithmic contains claims are corrected without changing either method.
