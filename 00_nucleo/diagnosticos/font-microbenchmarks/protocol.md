# Font microbenchmark protocol — first battery

Frozen before sampling. No production, L0, ADR, existing benchmark or prior evidence edits. This diagnostic crate uses existing public APIs, with an exact historical Coverage source slice as an explicitly identified algorithm comparator. It does not measure the historical crate or vanilla implementation. Vanilla pin remains 9f2b6e8715237cb086899a42873660fe744622e8; preserve its ratified provenance separately.

Inputs: the four exact font/face records in inputs.json, inherited from the previous experiment's fingerprint. Both constructors receive the same ordered, duplicate-preserving cmap sequence. Byte reads, face creation and validation are outside timers. Independent BTreeSet equality, canonical encoding equality and hit/miss assertions qualify the fixtures. cmap collection is a diagnostic ttf-parser traversal, not measurement of private extract_coverage.

Criterion 0.5.1: 30 samples, 5000 bootstrap resamples, 200 ms warmup, 600 ms target measurement per case. Three fresh executable runs; alternating fixture/constructor order (forward, reverse, forward). Warmups and preflight warm the filesystem and font bytes. This is not a cold-storage experiment. PerIteration batching excludes setup clones and returned result destruction. Constructor includes consumption/deallocation of its input Vec, allocations and interval/sort work. clone_and_build adds the clone. Metadata includes parser/metadata work, not coverage. First slot includes file access/mapping/parser/cache initialization, with fresh slot setup, input/output drop outside. Retained slot includes cached get and handle clone; returned Font drop excluded. Contains uses Criterion iter and black_box; bool has trivial destruction, loop/timer overhead remains. Queries are single fixed hit/miss points per case, not a representative fallback workload.

Require actual Cargo opt-level 3, debug assertions false and overflow checks false. Build.rs also fails timing registration unless opt-level 3 and debug assertions false. Clear ambient Rust flags and CARGO_PROFILE overrides. Save artifact profile, SHA-256, Cargo.lock, command, toolchain, flags, HEAD, exact dirty lists/patch and source/input hashes. Build tests/targets before timing, never concurrently. Compile all existing benchmarks with cargo bench --manifest-path benches/Cargo.toml --no-run --offline --locked --message-format=json.

Use CPU 4 for executable, Rayon one, driver CPU 6. Observe powersave/boost/frequency; change no global policy. Desktop/SO remain active. Thirty-second quiet gate before each round, 100 ms process monitoring during execution. Reject whole rounds for source/input/HEAD/executable changes, failed controls or observed concurrent tests/builds/benchmarks. Frozen source fingerprints include measured consumer trees, Cargo inputs, diagnostic implementation, historical snapshot and exact font bytes. Preserve rejected rounds and raw Criterion sample/estimate JSON. No reuse of another round's Criterion baseline.

Report per-case per-round iteration-normalized raw sample distribution: n, mean, median, sample SD, min/max, p05/p95; also Criterion estimates. Batching counts differ by sample. Three-round mean/median difference <3% (ADR-0115 descriptive criterion) and range of round means divided by their median <=5% required for stable absolute-cost classification. Failing cases stay descriptive; retain every round, never discard a slow round to rescue a claim. Compare constructor ratios within same font/round; not true interleaved pair samples, so do not call them paired differences or use an interleaved confidence interval. No addition to CLI total, no subtraction across fonts/caches/fixtures. This battery cannot assign remaining CLI-versus-vanilla gap to a single cause.
