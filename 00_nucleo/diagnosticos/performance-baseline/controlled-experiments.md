# Controlled experiments for candidate explanations

These are proposed experiments, not completed causal findings. No production
optimization or API addition is required to collect the first controls.

| Candidate | Controlled comparison | Evidence that would support it | Evidence that would refute or narrow it |
|---|---|---|---|
| Unused diagnostic project font changes world preparation | Same qualified source, executable, CPU and PDF options; alternate the recorded `--font-path fonts/` command with the same command omitting only that option. Selected Libertinus face bytes, output text and geometry must remain identical. | A stable change in wall/residual bounds the acquisition cost of this single unused face. This would qualify how representative the recorded font-universe baseline is of an invocation without that project path. | No repeatable change; any selected-face or visible-output change invalidates this control. |
| Eager versus lazy font acquisition shifts apparent phase costs | Use the existing public World/font and compile APIs on identical bytes; record world preparation and first font acquisition as their own diagnostic envelopes, then compare cold-process and explicitly prepared-world runs of the same document. Keep total lifecycle and output controls. | Cost moves from first layout/font use to preparation while total work stays comparable; an untimed profile identifies the acquisition paths. | Delta remains in layout after equivalent preparation, or preparation changes selected fonts/coverage. A smaller layout counter alone cannot establish a faster layout algorithm. |
| Font discovery/coverage contributes heavily to CLI residual | Same executable, input, selected face bytes, PDF options and CPU; compare default fontconfig with a diagnostic `FONTCONFIG_FILE` containing only the shared font directory. Both engines retain embedded fonts and receive the same unique math font. Verify identical selected faces, text and geometry, alternate A/B runs. fontdb 0.23 reads this variable in `load_fontconfig`; ensure the config has a non-empty directory list to avoid its fallback to default system directories. | A reproducible reduction in wall-minus-compatible-phase-sums, with phase/output controls stable, demonstrates a font-universe-dependent cost. An unmeasured profiler can locate loading, metadata or cmap traversal. | Residual does not fall, phase outputs change, or the engine ignores the config. It would not establish that disk reads alone cause the difference: parsing/coverage and allocation also vary with the font universe. |
| Registry assembly contributes to eval | Profile the *same* fixture's eval boundary and obtain an untimed invocation count of make_stdlib_with_features. Run the public registry API with exactly that fixture's Features/SysInputs, including destruction; compare expected count scaling across repeated evaluations. | Matching call frequency and measured registry envelope can bound its contribution to eval. A later authorized controlled implementation change would be needed for exclusive causal attribution. | Registry is absent/cached or negligible in the matched eval profile. The existing stdlib fixture's time alone cannot prove how often it runs in a real document. |
| Shape cache/repeated runs change costs | Diagnostic harness invokes existing public shape_document on the *same* PagedDocument/font bytes in fresh processes versus repeated calls in a warm process. Keep fixture construction/input clones outside timers and document whether output destruction is included. Do not expose private caches. | Stable reduction between first and later calls, identical glyph/text/position controls and profiles in shaping/cache paths. | No matched difference, or changes arise in font acquisition/clone/setup outside the shape interval. The current PDF stream cohorts cannot confirm this because they deliberately avoid production font shaping. |
| Context stabilization/repeated layout contributes | Same source, font/control options and process state, matched context-free/context-dependent inputs. Count existing vanilla `iter (n)` spans and retain Tekt expand/layout counters; use an equivalent visible output and record which computations are added. | Cost follows stabilization work and pass count under the matched intervention; useful attribution is the entire stabilization/layout envelope. | Counter boundaries move work between phases, the visible result/geometry differs, or the added context expression itself accounts for the cost. Do not infer that more passes necessarily mean slower compilation. |
| PDF export / serialization contributes | Same already shaped PagedDocument and face bytes through existing public export API. Compare only serialization mode or tagging at a time, verify visible controls and record the complete export boundary. For isolated emitter attribution use a sampling profile within this unchanged export, not a renamed benchmark group. | Whole-export differences reproducible under the single option intervention bound that option's incremental cost; samples may locate serialization/builder/stream candidates. | No reproducible delta, changed resource/tagging work, or a different document/font lifecycle. Never subtract dense from empty or builder from stream cohorts to estimate private emission time. |
| Content representation costs contribute | Profile allocations/traversals during the exact end-to-end fixture; obtain occurrence counts and test the existing public operation with matching tree shape/sharing. An A/B representation revision must be separate, authorized work with language controls. | Matched occurrences and operation envelopes locate a candidate; a controlled revision lowering both operation cost and compatible phase wall would support causality. | Large synthetic operation costs are rare/absent, cache sharing differs, or wall differences persist after a controlled intervention. Rust equality/hash timing is not a parity criterion. |

Instrumentation is itself a control: compare traced and untraced populations on
both sides. Their overhead is measured separately. A large trace penalty or noisy
rounds limits a small phase delta; it does not license subtracting a fixed global
correction from every sample.
