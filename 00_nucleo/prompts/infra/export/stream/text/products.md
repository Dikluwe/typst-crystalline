## Exclusive contract

Own borrowed Input, private request projection, exact key equality/hash index,
bounded L3 cache and complete operator suffix plus deferred-Q bit. No public
product API. Input carries the existing kernel operands without copying pages,
styles, fonts or contexts. Current CIDFont bitmap=None and resolved Multifont
with no bitmap qualify; Type1, missing/inconsistent mappings and bitmap decline.
Reject empty/over4096glyph requests, text over16KiB, units0, nonfinite positions,
nonpositive/nonfinite size, nonfinite tracking and spot fill. Ordinary emission
remains available with exactly its previous behavior. No user-facing limit.

Before lookup resolve the current Multifont index using the existing binding
helper, with bounds-checked access; resource index and scenario kind are key
facts. Read remapped GID (including empty-map identity/nonempty missing->0) and
nominal advance (including missing->actual advance) for EVERY glyph in order.
Compute current RGBA bits by the same nonspot conversion and actual render-mode
String through parent's shaped_tr_ops on CURRENT font/style. Store these results,
not font bytes or a belief that two faces are equal. Include position and size
bits, raw optional tracking length bits, units, restore/zero_alias, full glyph
fields/order and exact text. Full comparisons guard hash collisions; no Debug,
Rust float equality or address-only proof. Hash lookup is only an accelerator.

Use at most4096entries,4MiB total charged payload and256KiB per complete entry;
charge owned key glyph/text/render facts, projected mappings, entry/product
metadata and operator suffix before publication using checked arithmetic.
Capture into a fresh String only on admitted miss, then append to the caller's
existing ops. Hits append the immutable retained suffix and return its exact
deferred bit without cloning the suffix. No partial prefix/outer scope is stored.
Store only complete results within bounds; oversized result still appends in full.
Evict oldest/recently used entries coherently; no strong resource/style/World
owners survive a call. Cache poisoning/unavailability executes fresh emission.
Logical limits are not allocator/RSS guarantees. L3 private OnceLock/Mutex is
allowed for this pure immutable projection, with no mutable global in L1.
