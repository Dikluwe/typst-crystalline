## Callable and argument contracts

Each argument is evaluated once; shared converters and spread handling remain authoritative. Required positionals, excess positionals, unknown named arguments, duplicate options and invalid types must retain exact observable diagnostics. Ordered named validation uses `keys().next()` so the first invalid argument, span and any separate hint remain stable. No generic string-based dispatch or new math signature is authorized.

`bb`, `frak`, `inline`, `serif`, `mono` and `script` use the existing global native function identity and bare route. `script` defaults cramped to true. `inline` accepts only a boolean `cramped`. Missing body reports `missing argument: body`; wrong body reports `expected content, found <tipo vanilla>`; extras report `unexpected argument`; unknown names report `unexpected argument: <nome>`. Named `base`/`upper` where a positional is required retain their positional error and the separate hint `try removing <nome>:`. Unknown names retain the ordinary diagnostic.

`limits(body, inline: true)` requires a positional Content body. Keep `inline` presence independently from its value, including explicitly supplied true. It produces `MathLimitsOverride`; it does not lay out content. `scripts` uses the existing private ABI with limits false, inline true and inline-presence false; it must not synthesize pseudo-attachments using a `Sequence`. These limits contracts were explicitly approved on 2026-09-16.

`cancel` retains complete defaults: length 100% + 0.3em, inverted false, cross false, angle auto, stroke auto and background false. The previously approved runtime callback remains in its own owner and phase. `underline` takes exactly one positional Content body and no named arguments, produces the distinct math element, and preserves missing/unknown argument errors; it is not text underline.

`vec` takes variadic children, default delimiter `(`, center alignment and gap 0.2em. The vector child owns conversion, options and scope. `attach(base, t, b, tl, bl, tr, br)` preserves canonical slot order, Content base and six independent tri-state slots through its sole child builder; syntax and callable routes share that builder. `binom(upper, ..lower)` requires a nonempty lower sequence, preserves lower order and uses a line-free `MathFrac` with parentheses rather than a parallel payload.

`sqrt` takes one positional Content body, no named arguments, and produces `MathRoot(None, radicand)` with index-presence false. Math syntax sugar delegates to the same unit. It is neither a `√` Symbol nor `sym.sqrt`; numeric square root remains `calc.sqrt`. `root` takes exactly two positionals: index Content or None and a Content radicand, including normal None-to-empty conversion. Its index-presence is always true, including explicit None. Keep named-radicand positional hints, excess and unknown diagnostics. This contract was approved on 2026-09-16.

`frac` requires positional numerator and denominator, accepts only vertical/skewed/horizontal style, and applies the shared Content cast: Str and None are valid, Int is not. The frac child exclusively owns casts, spans, presence and identity. Accent's child owns base/accent aliases, size, dotless and explicitness. Cases' child owns delimiter and option conversion; matrix delegates directly to it rather than copying its table. Matrix's child owns row/options/padding/morphology/span policies and is bound before the symbol mirror. Its 29 historical tests retain only their original snapshot scope.

## Equation surface

`equation` requires a Content body and optional boolean `block` default false. Construct the semantic `Equation` through the same builder as syntax; do not use a missing-body None placeholder.

`numbering` accepts Str, Func or None and is stored as `equation.numbering`. Omission creates no style entry; explicit None disables numbering. It acts only on block equations. After fixpoint, a numbering Func receives the integer number and returns Content for render/reference use; the layouter never executes that Func.

`number-align` accepts `Align2D`. Its horizontal component permits start/left/right/end, rejecting center with `expected start, left, right, or end, found center`; Int reports `expected alignment, found integer`. Vertical values are top/horizon/bottom. Resolve omitted axes to end/horizon only in the consumer, preserving explicit representation before body realization. `set` handles numbering and alignment together rather than returning early after either field.

`supplement` accepts Content, Func, None or Auto; Str converts to Content, and Int reports `expected content, function, none, or auto, found integer`. Store it as `equation.supplement`. Omission means auto without an entry; explicit auto remains observable. A supplement Func receives the referenced Equation as its sole argument; its result follows display conversion, including Int, and errors propagate. Layout never executes it.

`alt` accepts Str or None. Omission, None and empty string remain distinct; reject Content with `expected string or none, found content` and Int with `expected string or none, found integer`. Local and set paths share the same style key and converter. Do not infer alt text from equation content.
