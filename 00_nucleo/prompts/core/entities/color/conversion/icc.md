Use immutable existing `typst_assets::icc::CMYK_TO_XYZ` bytes with the SHA above; do not import from lab, read filesystem/environment/network/clock, or fetch a profile dynamically. Decode checked big-endian profile data in RAM. Validate header/signature, source/PCS spaces, unique A2B0 tag, checked tag bounds, `mft2` type, 4→3 channel counts, matrix, grid and table dimensions, and exact length before indexing. Do not quantize stored CMYK values or constructor inputs. Return exact byte-normalized sRGB f32 components and alpha exactly one.

Evaluate actual input curves, four-dimensional profile CLUT, output curves and Lab-v2→Lab-v4 normalization. Preserve non-fused operation order evidenced by moxcms 0.8.1: normalized u16 samples, source-derived curves and interpolation, Lab PCS→XYZ, the inverse sRGB colorants matrix using `WHITE_POINT_D65` and BT.709, 4096-bin sRGB gamma projection to bytes, and the 17-node-per-axis sampled transform's scalar Q0.15 interpolation. Compute only required neighboring transform nodes in RAM if desired; equivalence is an inference supported by the measured prototype and must survive the public corpus. Use the exact scalar rounded-high multiply `(a*b + 16384) >> 15`, separate products and C/M/Y/K order demonstrated by the source; do not introduce calibrated compensation, CPU-dependent unsafe paths, ordinary float approximations, or an enlarged tolerance to hide a byte difference. These numerical details serve observable language results, not a requirement to duplicate upstream architecture.
