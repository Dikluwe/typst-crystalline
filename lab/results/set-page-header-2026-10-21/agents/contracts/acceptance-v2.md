These are proposed gate requirements, not implemented tests or measured outcomes. Bind each source/assets/argv/target to the ratified oracle commit/tree/recipe/binary SHA, the new baseline binary and exact HEAD/dirty inputs/UTC. Freeze source and expected language observations before productive changes. A baseline compiler/setup error is not a semantic RED. Actual tests may be added only after the correct owning L0 is current; public/phase changes require their exact approval first.

## Establish the actual omission

1. Preserve the original single-page header Figure plus body Figure source. Observe emitted body/caption token order, exact typed Figure counter values, query membership/kind/supplement/labels and actual Location positions/pages. The earlier F receipt is historical provenance; rerun the source against the new source-qualified baseline. A plausible caption from the synthetic fallback alone fails this gate.
2. Pair the progressive SetPage source with an explicit native page(header:…,body) control. Record their language results independently; do not assert that their internal trees or page boundaries must be identical.
3. Inspect baseline diagnostics and the assertion that fails. Require a language-level rendered/metadata/query discrepancy, not merely a private flag, different Rust representation, effect count or instruction path. Keep valid passing controls unchanged.

## Actual-emission and progressive scope

4. Set a header with a failing nested Figure/Context/supplement, override it before any material page, and compare with an actually emitted version. Measure unused-versus-reached errors and retained warning origins. Never equate installation with emission or change an expected panic to green by suppressing diagnostics.
5. Distinguish omitted delta, auto, none, empty Content and nonempty Content. Exercise inheritance across an unrelated page geometry delta, replacement mid-document, explicit pagebreak and an empty terminal body. Preserve automatic page-numbering suppression/eligibility and existing no-extra-page behavior.
6. Force the same header over multiple physical pages, with body Figures before and after boundaries. Freeze oracle query cardinality/order, each occurrence's page/position, typed at/final values and caption numbers. Include newly inserted raw Content and intentionally preexisting Located alias controls; do not guess one-per-template or one-per-page identity.
7. Nest a lexical PageRun with its own header and following outer content. Prove progressive configuration resumes correctly, with no artificial boundary/restoration from a SetPage→PageRun rewrite. Preserve native PageRun tests and container-rejection diagnostics.

## Figure semantics and temporal actions

8. Cover custom Name versus exact native Element kind, explicit kind/supplement versus inherited set/show-set, numbered/captionless/numbering:none and prepared alias reuse. Require exact language fields and typed keys, no productive figure:name shadow writes or ordinal recovery.

Preserve canonical original root membership while excluding hidden raw descendants. A captionless default Block retains the ratified body morphology and Location boundary. Full caption/default/Func-formatting debts remain explicit, not silently redefined by these tests.
11. Preserve labels and numeric/page references to header and body Figures, forward/backward targets, rich resolved supplement morphology and first-occurrence/query order. Keep all existing forty approved Ref controls, source-origin guards and unrelated heading/bibliography behavior unchanged.

## Captured styles, contexts and diagnostics

A captured Styled/ShowRecipe frame must not be replaced by the last body style; nearest Source/error trace and restoration after failure remain observable gates.

Measure ordinary/final physical page visibility; reuse the existing selected/unselected protocol and five-attempt budget. Ordinary located contexts remain successful.

A retained transaction publishes through the existing Sink policy; do not dedupe/cache/filter warnings to satisfy the fixture. Preserve original error precedence, source spans/hints/traces and call-depth termination.
15. Verify rich links, boundary geometry and decorative accessible running layers remain intact. Count/page/query values alone do not certify geometry or tagged-PDF semantics. Do not implement callbacks in the layout renderer to avoid the owning preparation gate.

Measurement alone does not authorize a new public API or phase. Direct Func marginal admission remains excluded unless separately decided; existing unsupported casts remain errors.
