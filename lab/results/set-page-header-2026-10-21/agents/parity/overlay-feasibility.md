## Feasible shape

An opaque `PageRunningBody` owning unchanged prepared Content plus a typed private source plan avoids ordinary Located/Styled wrappers and their paragraph/position/morphology side effects. The proposed new layout entrypoint consumes this body plan; legacy Content entrypoints carry `None` and take their current path. L3 transports opaque values and never chooses child fields or manipulates packet identity. No reverse entities-to-compiler import is needed.

The plan must have one closed Content partition, with explicit owner-typed child edges and child index where a field repeats. Example internal edges are `SequencePart(i)`, `StyledBody`, `SourceBody`, `LocatedBody`, `RealizedOriginal`, `RealizedVisual`, `FigureBody`, `FigureCaption`, `FigureSelectedSupplement`, `TableResolvedCell(i)`, `TableRawChild(i)`, `TableCaption`, `CellSelectedVisual`, `PageRunBody`, `QuoteBody`, `QuoteAttribution`, and the actual Grid/math/list/etc fields. This is a finite static enum/typed structure, not strings, trait objects, a global registry or a best-effort generic child lookup. New Content variants must fail the plan partition at compile time. A child address is scoped to that exact immutable plan generation; it is not a numeric Location or a language identity.

At each source child transition the feature owner explicitly enters `parent.child(edge)` and dispatches the original Content with that cursor. Returning restores the caller cursor. The driver verifies the edge was declared at that parent and enters its exact planned packet; no pointer/hash/equality matching guesses which raw clone this is. Locatable semantic identity remains a separate field recorded by the source plan and arena. A typed packet can contain no language Location (for a nonlocatable label effect) or several auxiliary operations at one canonical Location.

The normal root registration boundary admits the current packet. Source/Styled carriers advance their typed edge without adding semantic membership; Located transports existing identity under its current rules. Realized has separate original-only semantic registration and actual visual descent, preserving the existing Table/Figure/Block exceptions. Synthetic renderer output enters explicit `Generated`/None mode and cannot accidentally consume a source packet. Source children embedded inside synthesized wrappers require an explicit projection route to the declared source child, not an unlocated wrapper that steals its parent's cursor.

## Non-direct paths that the finite scope must explicitly include or prove inert

1. **Sequence/paragraph planning**: `sequence.rs:36-55,62-107,112-332` can return through paragraph-plan success instead of ordinary child dispatch, and segmented columns enter Sequence directly. Audit `paragraph_plan.rs`, `paragraph_prepare.rs`, `paragraph_emit.rs`, `paragraph_select_bounded.rs` and its delegated units, `bidi_origin.rs`, `sequence/inline_prefix.rs`, `sequence/fractional_preflight.rs`, `columns/segmented.rs`. A source plan cannot rely on all source leaves calling layout_content. The classifier remains unchanged; packet admission follows whichever existing path actually emits the source operation. Pure certified text has no semantic operation, so an explicit proof allows a cursor-free fast path; do not broaden that proof to opaque metadata/Context/updates.

2. **Isolated measurements**: `paragraph.rs:265-423` builds isolated Layouters and cloned/synthetic Sequences; `measurement.rs`, `grid/tracks.rs`, `boxed.rs`, and `tiling.rs` also use measurement/subframe routes. These must pass None/measurement mode, not admit real events or consume resolutions. If a clone later becomes actual emission, the owner must restore the exact original child cursor independently. Source address must not be derived by comparing the cloned Content to the original.

3. **Subframe state**: `sub_frame.rs:65-490` manually saves/restores many fields and dispatches Content at263/490. Its plan scope and emitted event suffix must be checkpointed/restored just like current_location, source span, style and position captures. A semantic emission subframe returns its accepted event block to its actual parent in composition order; a speculative measurement returns no admitted block. Returning geometry is not permission to merge all observed effects.

4. **Transactions/deferred placement**: `checkpoint.rs` and `flow_suffix.rs:28-91` must capture cursor, event suffix, resolution consumption and any queued child address together. Flow replay stores cloned Content, so replay buffers need the corresponding owned plan cursor/address. `placement.rs`, `place.rs`, `footnote.rs`, `footnote_flush.rs`, `line_commit.rs` and `columns/{flow,segmented,transitions}.rs` must carry the address with delayed child work. An address cannot be reconstructed from a later Frame or sorted position. Root tokens emitted in a rejected trial disappear with that trial; accepted prefix remains intact.

5. **Table/Grid selected snapshots**: `table.rs`, `table_cell.rs`, `grid/tracks.rs` and `grid/cell_body.rs` choose prepared cells, sometimes synthesize alignment/Block wrappers, and sometimes measure a different projection. Use distinct selected semantic/visual source edges. Preserve raw versus resolved/standalone selection already specified by each owner; do not reenter dormant body/header/footer snapshots or reactivate show-hidden originals. Source packet parents follow canonical source semantics, not the synthesized wrapper stack.

6. **Generated output**: Figure caption Sequence/Block, Heading number prefix, Quote punctuation, citation text, state/counter pre-rendered output, bibliography entry formatting and outline title/entry formatting are explicit generated paths. None is valid only where the current owner treats that output as presentation rather than a new actual semantic contribution. When a generated wrapper contains an already admitted source child, select its declared child cursor inside the wrapper and leave only the prefix/suffix generated. References to another element's body (notably OutlineEntry) are not fresh source insertion packets. This classification must follow current L0, not a blanket all-generated-is-inert shortcut.

7. **Math handoff**: `layout/equation.rs` sends a Content body to `compiler/math/layout`, outside ordinary layout_content descent. The final plan must declare the existing equation's semantic descendants as a single atomic physical-page block only if that is valid for their current location contract, or enumerate actual math owner transport. It cannot silently mark all math Content as nonsemantic because it does not appear in the direct method inventory. No new math callback/Context phase is implied.

8. **Physical layers and PageRun**: `page_canvas.rs`, `page_running.rs`, `page_commit.rs`, `finish.rs` and `page_run.rs` must select one of four physical slots and its retained instantiated plan. Existing PageRun static template semantic walk must not coexist as a second action source. PageRun lexical config restoration and SetPage progressive overrides remain distinct. A selected running plan's source root does not inherit a body parent's cursor. Each actual raw physical insertion gets its retained frame; already Located aliases keep their existing identity semantics.

## Acceptance and finite-scope gate

The overlay is feasible as a static Tekt design; it is not a small two-file adapter. The exact final owner manifest and typed edge inventory must cover all actual bypasses above, or explicitly prove an owner has no semantic packets and retains None. This is an engineering gate before asking approval for the public body/preparation APIs. It must not be silently expanded during implementation.

Require two correlated witnesses: a fictitious Content variant fails the complete plan decision; and a missing/foreign/wrong-parent child-edge admission fails closed before Complete. Preserve existing legacy render/classifier behavior with None. Test source snapshots and paragraph morphology unchanged; nonpaint actions; parent across pages; flow rollback; columns; selected table cells; deferred footnotes/floats; generated caption child routing; measurement no effects; repeated raw versus Located aliases; all four slots and HTML nonadmission. Source/event parents remain independent of flattened physical tag order.

ADR-0071 needs explicit review: it ratified intr-accessible incremental semantic construction and rejected a two-walk implementation with duplicated state effects. A source plan followed by physical construction may retain the useful incremental population semantics, but its compatibility must be stated in the final gated design rather than presented as unchanged legacy machinery. ADR-0073/0074 continue to forbid replacing this with global Frame introspection.
