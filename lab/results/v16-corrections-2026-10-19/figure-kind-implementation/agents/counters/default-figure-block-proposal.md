## Measurement before classification

The source `agents/entities/reference-acceptance/hidden-reference-parent.typ` globally applies `show block:none`, emits a captionless outer Figure with an unused nested Figure supplement, then emits an explicit Block containing its reference. Pinned oracle receipt records empty rendered text and query `[[1,[0],[1],1]]`. The immutable pre-reference-product-2 receipt already records `OUTER` with the same query. Those receipts bind full source, binary identities, argv and measurement times. This establishes a pre-existing rendered-language gap before the new Ref phase. The initially permissive empty token-count map did not prove empty render; the later strict policy must stay intact.

The verified oracle is commit bd5ebec285505889e8ff1d4f68804ab147a699f3, tree cac836c07e4dec2a89219370428292393a3216b5, binary SHA-256 9b2373155e9c05bbb0daf5755bf4be88a11e64bd6b4f8b376648fa27303373b9. Its `typst-layout/src/rules.rs:310–335` builds Figure's visual body/caption sequence, appends a paragraph break and wraps the product in a real Block before ordinary realization continues. Library `model/figure.rs:434–442` provides Figure show-set defaults, including Block breakability. This is evidence for observable Block show semantics, not a requirement to copy upstream Rust structure.

Tekt `realize/recipes.rs:494–502` retains the prepared Located Figure as original and realizes its Figure-shaped visual children. `layout/figure.rs:112–139` directly emits body/caption with paragraph boundaries. It creates no Block language object for normal block selectors/replacements. Current layout L0 explicitly authorizes paragraph-flow repair, while current realization L0 retains complete caption synthesis as debt. Neither establishes a complete generated Block/caption representation. The query agreement isolates this failure from typed automatic action membership and Ref child admission.

## Required semantics

Retain the prepared canonical original Figure at exactly its existing Location, with its typed kind, original lexical/resolved supplement template, label and numbering eligibility. Register its automatic action once. Construct its default visual product only after Figure's own root preparation and own show/replacement decision. A replacing Figure rule owns its returned product; it must not acquire an invented extra default Block.

For the default product, a real ordinary Block must receive normal show-set, selector and replacement handling before any child is visited. `show block:none` must prune body/caption/context/nested-supplement effects, while the already prepared original Figure still exists and counts. Source, active rule guards and lexical styles remain authoritative. No manual rule lookup, layout callback, fake hidden flag, extra Context member, second arena or result cache is acceptable.

A Block callback must see the actual body/caption product as language content. Wrapping a still-semantic Figure inside Block merely to reach a selector exposes the wrong `.body` morphology and risks recursively regenerating Blocks. A private token alone does not resolve that language mismatch.

## Concrete implementation options and unresolved boundary

1. A captionless default-product slice can use existing public `Content::Block`, its existing element fields, body plus `Parbreak`, and existing realization. Preserve `Realized.original` and the existing Located identity for layout position capture; visit only the actual Block visual afterward. This directly addresses the frozen captionless source without executing dormant supplements. It is not a complete Figure implementation. Before authorizing even this slice, measure and specify Figure page/outline registration and location transport: removing the visual Figure bypasses its current layout registration, so counter agreement alone is insufficient.
2. A coherent all-Figure product additionally requires actual caption content before child realization. Current `layout/figure::layout` computes typed numeric prefix from the finalized introspector only during layout. Moving that calculation into early realization would read an incomplete snapshot and change phase. Retaining a Figure node only as a hidden numeric renderer inside Block also exposes incorrect morphology and may duplicate actions/paragraphs. A valid design must select an existing delayed caption/counter content mechanism with the original Figure Location and complete demanded history, or separately specify a new carrier/phase. This draft has not selected or proved such a mechanism.

No new public signature, entity field or trait is proposed or authorized here. Existing Content/Block reconstruction may suffice for option1; that is a design constraint, not proof. If option2 needs a public carrier or moves caption calculation across phases, list exact declarations and the full phase order in a separate review before implementation. Function-number formatting, caption placement/gap/default fields, floats and HTML remain outside a captionless slice unless separately measured and specified.

## ADR-0127 classification

The objective is measured vanilla language convergence, so a rendered-output change alone falls under continuous-flow §2 item3; it is not automatically a new product-intent default. However, default Figure-to-Block synthesis introduces an observable product path absent from current L0, and solving numeric captions may move work from layout into realization or add a public carrier. Those are distinct stop categories. The captionless slice could be continuous if review proves existing phase/contract/compatibility remain intact. The full correction is currently unclassified because the numeric-caption mechanism is unresolved; ADR-0127 requires stopping to classify uncertainty. This diagnostic does not request permission or infer approval from the Ref extension.

## Acceptance before implementation and closure

Freeze the existing strict source and add bilateral controls for ordinary/default Figure output; captionless and numbered captions; own-Figure replacement versus generated-Block replacement; Block callback `.body` morphology; show-set Block styles; nested replacement pruning before callbacks; source errors/warnings; typed global/per-kind counts and same original query Location; labels/references/outlines/pages; fresh templates and prepared aliases; source and generated Context membership; finite/cyclic references; HTML isolation. Measure callback effects as language errors/warnings, not invocation-count equivalence.

Functional RED must establish the chosen scope before L0/code. Preserve all prior Figure/Grid/Ref controls and strict policies. Require source/owner cardinality and hashes, lineage/path checks, structural extension probes, complete diagnostic differential and the existing workspace/build/Clippy/Rustdoc/test gates. A captionless positive result cannot certify complete caption synthesis or whole-language parity.

## Captionless slice feasibility after source and oracle review

The separate `default-figure-block-oracle/receipt.json` freezes three new actual pinned-oracle controls and exact sources/argv/UTC. A Block callback observes `sequence(strong(body:[BODY]),parbreak())`; its child functions are `(strong,parbreak)`. Default fields measured through that callback are breakable=false, width/height=auto and inset=(:). `show figure:set block(breakable:true)` changes the generated Block's breakability to true. These are source/content observations, not geometry or byte identity.

A narrow same-phase implementation is feasible without public API change: preserve prepared Located(Figure,L) as canonical original; build the real captionless Block from the still-unvisited raw body plus Parbreak; send it through existing normal recipes before descending; store the resulting actual visual with the same original Location. The generated Block contains actual content rather than another Figure, so ordinary Block callback `.body` morphology and recursion are well-defined. None/replacing Block recipes can prune children before effects, while the original Figure still counts. A custom replacing Figure recipe owns its returned product; it receives no invented default Block unless its result itself contains a reached Figure.

Page ownership is concrete for this slice: productive layout/figure.rs registers figure_page_numbers only in the caption-present branch. Captionless Figures add no such entry today, and figures_for_lof stores captioned entries. `layout/realized.rs:558–576` registers prepared original positions, then dispatches the actual visual; `layout/mod.rs:1255–1277` already records the explicitly supplied visual Location. Preserve that protocol and verify the same Location/page under normal, hidden and replaced generated Block controls. No caption-number lookup moves to realization, and no new Location is allocated for the generated Block.

This supports **continuous correction for the captionless slice**, because ADR-0127 explicitly excludes vanilla rendered-parity corrections from new-product-intent default gating. This conclusion does not authorize code by itself or classify a full numbered-caption redesign. L0 and independent functional RED are still required before implementation.

Existing Block limitations remain material. `content_methods.rs:114–120` currently declares only width/height/body, so complete reflected breakability is pre-existing debt. `rules/set.rs:305–334` currently supports only Block spacing/above/below style entries; Figure show-set breakability cannot be claimed solely by constructing a baked false field. The initial slice can establish ordinary Block replacement and actual `.body` morphology through existing contracts; default style handling must be explicitly specified and measured rather than advertised as complete. No manual show-rule interpretation or extra Align language wrapper is an acceptable shortcut for Figure's ordinary default style chain.
