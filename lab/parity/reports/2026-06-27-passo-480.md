## Sub-item A — Outline-toc heading count (RESOLVIDO)

**Medições** (ADR-0108):

| Medição | Resultado | `file:line` |
|---------|-----------|-------------|
| Corpus `outline-toc.typ` query `heading` — cristalino pré-P480 | count=5 | pré-P480 |
| Corpus `outline-toc.typ` query `heading` — vanilla 0.14.2 | count=6 | vanilla CLI |
| Walk arm `Content::Outline` pré-P480 | Vazio (P189B) | `introspect.rs:1225` |
| `outline::layout` cria heading de título? | Sim (durante layout) | `outline.rs:57` |
| `headings_for_toc` sub-store — deveria incluir outline title? | Não (causaria TOC auto-referente) | ADR-0108 intenção vs comportamento |

**Decisão**: registo sintético em `kind_index[Heading]` no walk arm `Content::Outline`, sem tocar `headings_for_toc`.

A abordagem da spec (Sequence com Heading real) foi rejeitada: o walk arm `Content::Heading` adicionaria o título de outline a `headings_for_toc`, causando que `layout_outline` listasse "Índice" como entrada do próprio índice — TOC auto-referente.

**Fix** (`01_core/src/engine/introspect.rs`):

```rust
Content::Outline(_) => {
    let title_loc = locator.next();
    intr.kind_index
        .entry(ElementKind::Heading)
        .or_default()
        .push(title_loc);
}
```

**Resultado**: cristalino=6 = vanilla=6. `headings_for_toc` inalterado (apenas headings reais).
