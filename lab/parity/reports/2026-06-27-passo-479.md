**Causa raiz identificada P479:**

Headings criados durante layout são invisíveis à query pré-layout.

**Classificação:** divergência arquitectónica (pré-layout vs pós-layout query).
**Magnitude fix:** M — requer mudança tripla (walk/layout/native_outline).
**Acção P479:** documentado como INCLUDE-com-diff; scope-out P479.

## Fix materializado: `cite-bibliography` heading (S-size)

### Sonda pré-fix

| Medição | Resultado | file:line |
|---------|-----------|-----------|
| `visual/cite-bibliography.typ` query `heading` cristalino | count=0 | pré-P479 |
| `visual/cite-bibliography.typ` query `heading` vanilla | count=1 | vanilla 0.14.2 |
| `BibliographyElem.title` default | `None` | `structural.rs:1376` (pré-P479) |
| `walk` arm `Content::Bibliography` recursivo em `e.title`? | **Sim** | `introspect.rs:1164–1168` |
| `bibliography::layout` renderiza `e.title`? | **Sim** | `bibliography.rs:29–32` |

**Conclusão:** Caso real. Vanilla gera heading para o título da bibliografia por defeito. Cristalino não gerava título, logo introspector pré-layout não contava heading. Fix: definir título padrão como `Content::heading(1, "Bibliography")` em `native_bibliography`.

### Implementação

**Ficheiro:** `01_core/src/rules/stdlib/structural.rs`

```rust
// Antes (P159A):
let title = args.named.get("title").and_then(|v| match v {
    Value::Content(c) => Some(c.clone()),
    Value::Str(s)     => Some(Content::text(s.as_str())),
    Value::None       => None,
    other             => Some(Content::text(other.type_name())),
});

// Depois (P479):
let title = match args.named.get("title") {
    Some(Value::Content(c)) => Some(c.clone()),
    Some(Value::Str(s))     => Some(Content::text(s.as_str())),
    Some(Value::None)       => None,
    Some(other)             => Some(Content::text(other.type_name())),
    None => Some(Content::heading(1, Content::text("Bibliography"))),
};
```

**Porque funciona:**
1. `walk` arm `Content::Bibliography` (`introspect.rs:1164`) recursivo em `e.title` → quando `e.title = Some(Content::heading(1, ...))`, o walk encontra um `Content::Heading` e emite payload `Heading` → contado pelo introspector.
2. `bibliography::layout` (`bibliography.rs:29`) chama `layout_content(t)` onde `t = Content::heading(1, ...)` → heading renderizado via arm heading do layout. Zero dupla renderização.
3. `title: none` → `None` preservado. `title: "Custom"` → `Some(plain text)` preservado.
