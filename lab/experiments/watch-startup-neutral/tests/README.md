Compara cada nova sessão ao builder público fresco. Configuração Fontconfig explícita evita dependência de fontes do host e pode impedir fast eligibility: estes são testes de frescor, não uma simulação de watch completo. A estabilidade dos bytes antigos é exigida após rename atômico; escrita in-place não transforma um mmap antigo em snapshot imutável.
- `check_evidence.py --phases /dev/shm/.../phases.tsv`: aceita somente o contrato acordado `pid<TAB>cycle<TAB>label<TAB>calls<TAB>ns`, sem header. Valida identidade, monotonicidade por processo, labels únicos, eventos sem duração, terminais e contagens/short-circuit de sessão. Fases são inclusivas; limites com múltiplos pais não são uma partição nem atribuição causal. Fast eligibility nunca é pressuposta.

Variantes `bas,neu,laz`, trio completo por batch/recipe/fixture/imports/roots.
